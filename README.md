## ✨ Funcionalidades Principais

1. **Identidade Visual Autêntica:**
   - Paleta de cores inspirada na marca da Solforte (laranja caloroso/âmbar do sol, preto carvão e detalhes em ouro).
   - Logotipo oficial vetorizado e exibição das artes institucionais de história e canais de contato.

2. **Simulador de Frete Interativo:**
   - Permite que clientes simulem rotas (Carga Lotação ou Fracionada), informem peso e características, gerando propostas formatadas com 1 clique para o WhatsApp Comercial.

3. **Rastreamento de Cargas:**
   - Campo para consulta de CTe, Chave de Acesso ou Nota Fiscal com redirecionamento direto à central de tráfego.

4. **Apresentação Institucional & História:**
   - Resgate fiel da história e pilares da empresa: Agilidade, Honestidade, Rigor na Segurança e Custo-Benefício.

5. **Malha Rodoviária & Rotas:**
   - Destaque para o entroncamento logístico estratégico de Jequié/BA (BR-116 e BR-330) conectando o Nordeste ao Sudeste e Brasil.

6. **Contato e Localização:**
   - Mapa interativo de Jequié integrado, formulário de contato direto e botão flutuante de WhatsApp ativo em todas as páginas.

7. **100% Responsivo:**
   - Perfeito em smartphones, tablets e desktops de qualquer resolução.

## 🚀 Tecnologias Utilizadas

- **Framework / Bundler:** [Vite](https://vitejs.dev/)
- **Linguagem:** TypeScript + React 19
- **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Otimização:** Google Fonts (*Outfit* e *Plus Jakarta Sans*)

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar as dependências
pnpm install
# ou
npm install

# 2. Iniciar o servidor de desenvolvimento
pnpm run dev
# ou
npm run dev

# 3. Gerar a versão de produção
pnpm run build
```
